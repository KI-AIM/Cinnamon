Supported File Types:

Supported file types are:

  • CSV Files
  • XLSX Files
  • FHIR Bundles (with limitations)

The support for FHIR bundles is still in development and has some limitations. Currently, only one resource contained in the bundle can be imported and anonymized at a time. If the bundle contains multiple resources, each one must be anonymized in a separate project. Furthermore, FHIR bundles can only be exported in tabular form as CSV or XLSX files. The column names correspond to the values' FHIR path and cannot be changed.

To import a dataset into Cinnamon, you can either upload a file containing your dataset from your local machine or fetch the dataset from a FHIR server.

Data Source Description
Local Files Selecting this source lets you upload a file containing your dataset from your local machine.
FHIR Servers This data source offers the ability to fetch the dataset from a FHIR server.

The configuration file contains the data configuration, which specified the attributes inside the dataset. It has to be created specifically for the attributes contained in the dataset. You can obtain a configuration from a previous project which used the same attributes. In case you don't have a configuration file, you can continue without a configuration. The data configuration will be estimated based on the selected dataset and can be adjusted afterwards.

The FHIR server URL is the address of the FHIR server from which the dataset will be fetched. It has to include the entire FHIR search parameter. For more information see the official FHIR Search documentation.

FHIR Server URL Explanation
https://example.com/fhir/Patient?id=123 Fetches the patient resource for a specific patient with ID 123.
