Use hyperparameter tuning?
Sampler TPE Grid NSGA-II info

Algorithm used to propose hyperparameter combinations. Grid exhaustively tests all combinations, TPE performs Bayesian optimisation, NSGA-II is a genetic algorithm for multi-objective search.

Pruner None Median Hyperband Successive Halving info

Strategy for early-stopping unpromising trials. "None" lets every trial run to completion; Median stops trials below the median of completed ones; Hyperband and Successive Halving allocate budget adaptively across trials.
